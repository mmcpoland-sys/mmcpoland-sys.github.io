# Matt McPoland | Athletic History

A family sports-history archive, designed for GitHub Pages.

## Publishing

Upload **index.html**, **styles.css**, **script.js**, and the entire **assets** folder to the root of your `mmcpoland-sys.github.io` repository. Do not upload the ZIP itself. GitHub Pages is already enabled on `main` at `/(root)`. Wait a few minutes for deployment.

## Content notes

This is a first version using documented scrapbook facts, personal recollections and selected original award photographs. The searchable archive indexes highlights; the complete scrapbook scans and 1996 PLU pitching totals have not yet been added. The 1995 Fireman's Award meaning is based on Matt's recollection. Sensitive ID photos are intentionally excluded.

Edit `index.html` for page text, `styles.css` for visual design, and `script.js` for archive entries.

## Search engine setup (October 2026)

This version includes four dedicated sports pages, metadata, structured data, sitemap.xml and robots.txt. After publishing, open https://search.google.com/search-console, add the URL-prefix property https://mmcpoland-sys.github.io/, complete the verification method offered by Google (HTML file upload is often simplest on GitHub Pages), then submit sitemap.xml under Sitemaps. For Bing, visit https://www.bing.com/webmasters/ and add the site. Search engine indexing is not guaranteed.
